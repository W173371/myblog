# 为什么会有这个想法

因为我不懂代码，所有功能都是先有想法，然后交由AI生成代码，我来负责测试功能是否实现，并将结果告知AI，再进行调整。    
如此往复过程中，遇到了一个问题：AI在解决了原有问题，增加新功能过程中，会导致原功能也被搞乱了。   
所以迫切需要代码版本的管理。  
这样，可以不断迭代更新，不至于影响原有功能。  
本文记录关于代码版本管理的一些尝试。    

# 代码管理知识整理
## 1.什么是版本管理？
一句话定义：用工具记录代码文件的每一次历史变更，让你能随时回到任何一个历史状态，并支持多人协作。  
游戏存档类比：  
本地仓库 = 你电脑上的游戏进度

暂存区 = 选好了要保存的文件，但还没确认存档

提交 = 真正创建一个存档点（如“打败Boss前”）

远程仓库 = 云存档（防丢失、可协作）
---------以上是DS总结--------
个人理解：在没有开启版本管理时，本地代码都是实时的，就像眼睛一样，。  
开启了版本管理以后，就像快照一样，可以进行存档了。  
git是本地的存档，存档的版本可以放云上上，也就是github这类工具的作用。

## 2.Git 与 GitHub 的区别

Git ：	  
性质：一个工具（命令行/软件）  
作用：在本地电脑上管理代码版本  
联网：	不需要（提交、查看历史都在本地）  

GitHub：  
性质：一个平台（网站/云服务）  
作用：在云端托管代码仓库，实现协作  
联网：需要（上传、下载、协作需联网）  
其他类似 GitHub 的平台：GitLab、Gitee（码云）、Bitbucket、Azure DevOps。

一句话总结：Git 是“引擎”，GitHub 是“云服务器”。
## 3.Git 的基础操作（最常用命令）
3.1 单人使用（创建存档）
>git init                  # 初始化仓库（只需一次）  
>git add .                 # 把所有改动加入暂存区  
>git commit -m "提交说明"   # 创建存档  
>git log --oneline         # 查看历史存档

# 在本地如何使用GIT

好的，我来给你一个**从零开始在本地使用 Git** 的完整实操指南。假设你之前完全没用过 Git，跟着下面步骤做就行。

---

## 1.确认 Git 是否已安装

打开你的终端（Terminal）：

- **Mac**：按 `Cmd+空格`，输入 `terminal`，回车
- **Windows**：按 `Win+R`，输入 `cmd`，回车
- **VS Code/CodeBuddy/Trae**：按 `` Ctrl+` `` 打开内置终端

输入以下命令：

```bash
git --version
```

**如果显示版本号**（如 `git version 2.39.5`）：✅ 已安装，跳到第二步。

**如果显示 `command not found`**：❌ 需要安装。

### 1.1 安装 Git（如果没有）

- **Mac**：终端执行 `xcode-select --install`
- **Windows**：去 [git-scm.com](https://git-scm.com) 下载安装包，一路下一步
- **Linux**：`sudo apt install git`（Ubuntu/Debian）或 `sudo yum install git`（CentOS）

安装完再执行 `git --version` 确认。

---

## 2.设置你的身份（只需一次）

告诉 Git 你是谁，这样每次提交都会带上你的名字和邮箱：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱@example.com"
```

例如：
```bash
git config --global user.name "张三"
git config --global user.email "zhangsan@example.com"
```

**验证配置**：
```bash
git config --global --list
```

---

## 第三步：实际使用 Git（三种场景）

### 场景一：从一个已有的代码文件夹开始

假设你已经在 `C:\my-project` 或 `/Users/你/Desktop/my-project` 里写了一堆代码。

**1. 进入这个文件夹**

```bash
cd /你的项目路径
```

例如：
```bash
cd ~/Desktop/my-project   # Mac
cd C:\Users\你的名字\Desktop\my-project   # Windows
```

**2. 初始化 Git 仓库**

```bash
git init
```

你会看到：`Initialized empty Git repository in ...`。这会在文件夹里创建一个隐藏的 `.git` 目录（别动它）。

**3. 查看当前状态**

```bash
git status
```

你会看到红色的文件名，表示这些文件还没被 Git 管理。

**4. 把文件加入暂存区**

```bash
git add .
```

`.` 表示所有文件。你也可以单独添加某个文件：`git add index.html`

**5. 提交（创建第一个存档）**

```bash
git commit -m "第一次提交"
```

**完成！** 你的代码已经被 Git 管理起来了。

---

### 场景二：从一个空文件夹开始写代码

**1. 创建并进入文件夹**

```bash
mkdir my-new-project
cd my-new-project
```

**2. 初始化 Git**

```bash
git init
```

**3. 创建一个测试文件**

```bash
echo "hello world" > readme.txt
```

**4. 提交**

```bash
git add readme.txt
git commit -m "添加readme文件"
```

---

### 场景三：从 GitHub 下载别人的项目（克隆）

```bash
git clone https://github.com/用户名/仓库名.git
```

例如：
```bash
git clone https://github.com/facebook/react.git
```

这会把整个项目下载到当前文件夹。

## 第四步：日常开发循环（最重要）

你每天写代码的流程应该是这样的：

```bash
# 1. 写代码...（用你的编辑器正常写）

# 2. 看看改了什么
git status

# 3. 把改动加入暂存区
git add .

# 4. 提交（创建存档）
git commit -m "修复了登录按钮的bug"

# 5. 继续写代码...重复 2-4
```

**查看历史提交**：
```bash
git log --oneline
```

你会看到类似：
```
a1b2c3d 修复了登录按钮的bug
e4f5g6h 第一次提交
```

## 第五步：在 VS Code/CodeBuddy/Trae 中使用（不用记命令）

如果你不想敲命令，这三个编辑器都内置了图形化 Git 界面：

### 操作步骤（三款工具通用）：

1. **打开 Git 面板**：按 `Ctrl+Shift+G`（Mac：`Cmd+Shift+G`）

2. **你会看到左右两栏**：
   - 左侧：更改的文件列表（红色 M 表示修改，绿色 U 表示新增）
   - 右侧：文件内容对比

3. **暂存文件**：点击文件旁边的 `+` 号

4. **输入提交信息**：在顶部输入框写说明（如“修复登录bug”）

5. **提交**：点击 `✓` 按钮

6. **查看历史**：点击面板右上角的 `...` → `查看历史`

## 一个完整的练习：从头到尾做一遍

跟着做，10分钟就能上手：

```bash
# 1. 创建一个练习文件夹
mkdir git-practice
cd git-practice

# 2. 初始化
git init

# 3. 创建第一个文件
echo "# 我的项目" > README.md

# 4. 提交
git add README.md
git commit -m "初始化项目"

# 5. 修改文件
echo "这是第一行内容" >> README.md

# 6. 查看状态（会显示 README.md 被修改了）
git status

# 7. 再次提交
git add README.md
git commit -m "更新README内容"

# 8. 查看历史
git log --oneline

# 9. 创建一个新文件
echo "console.log('hello')" > app.js

# 10. 提交新文件
git add app.js
git commit -m "添加app.js文件"

# 11. 查看所有提交
git log --oneline

# 12. 查看某个提交的具体内容（用你看到的ID替换）
git show 刚才的提交ID
```

## 常见问题速查

| 我想做什么 | 命令 |
| :--- | :--- |
| 看当前改了哪些文件 | `git status` |
| 看具体改了啥内容 | `git diff` |
| 放弃某个文件的修改 | `git checkout -- 文件名` |
| 撤销上一次提交（保留修改） | `git reset --soft HEAD~1` |
| 删除文件并记录到版本库 | `git rm 文件名` |
| 查看所有分支 | `git branch` |
| 创建新分支 | `git branch 分支名` |
| 切换分支 | `git checkout 分支名` |

---

## 最重要的一句话

**你只需要记住 3 个命令就能开始：**

```bash
git add .          # 把所有改动加入“待提交列表”
git commit -m "说明" # 创建存档
git status         # 看看现在什么状态
```

其他命令，用到的时候再查就行。
